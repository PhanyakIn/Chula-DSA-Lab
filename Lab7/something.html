Convex polygon triangulation • น้ำหนักสามเหลี่ยม = เส้นรอบรูป (perimeter) • หา triangulation ที่ผลรวมน้อยสุด

1. โจทย์พูดอะไร? (Intent)

Triangulation ของ convex polygon คือการลากเส้นทแยงมุม (diagonal) เชื่อมจุดยอดที่ไม่ติดกัน โดยเส้นต้องไม่ตัดกัน จนทั้งรูปถูกแบ่งเป็นสามเหลี่ยม n−2 รูป (ถ้ามี n เหลี่ยม)

Cost ของ triangulation หนึ่ง = ผลรวมเส้นรอบรูปของสามเหลี่ยมทุกชิ้น:
cost(T) = Σ perimeter(t)  โดย perimeter(a,b,c) = dist(a,b)+dist(b,c)+dist(c,a)

เป้าหมาย: เลือกวิธีลากเส้นให้ cost รวมน้อยที่สุด — รูปเดียวกันลากคนละแบบ cost ไม่เท่ากัน (ดูรูป pentagon ด้านล่าง)

Pentagon (n=5) มี triangulation ทั้งหมด Catalan(3) = 5 แบบ • Hexagon (n=6) มี Catalan(4) = 14 แบบ

3. Recurrence (สิ่งที่ข้อ 1 ของใบงานถาม)

ให้จุดเรียงตามขอบ 0..n−1, dist(i,j) = ระยะยุคลิด, w(i,k,j) = dist(i,k)+dist(k,j)+dist(i,j)

dp[i][j] = 0 ถ้า j − i < 2 (มีไม่ถึง 3 จุด → ไม่มีสามเหลี่ยม)
dp[i][j] = mink: i<k<j ( dp[i][k] + dp[k][j] + w(i,k,j) ) ถ้า j − i ≥ 2

คำตอบ = dp[0][n−1]

ทำไมถูก? polygon ช่วง i..j ถ้ามี ≥3 จุด สามเหลี่ยมที่ติดขอบ (i,j) ต้องมีจุดที่สาม k สักตัว มันแบ่งช่วงออกเป็นซ้าย i..k + ขวา k..j + สามเหลี่ยมกลาง (i,k,j) — ลองทุก k เอาถูกสุด = optimal substructure แบบเดียวกับ Matrix-Chain Multiplication

ลำดับการเติมตาราง: เติมตาม gap = j−i จาก 2 → n−1 (เส้นทแยงสั้นก่อนยาว) • เวลา O(n³) (มี O(n²) ช่อง × ลอง k O(n)) • พื้นที่ O(n²) • เทียบกับ brute-force ที่ต้องลอง Catalan(n−2) ~ 4ⁿ/n^1.5 แบบ

for gap in 2..n-1:
  for i in 0..n-1-gap:
    j = i+gap
    dp[i][j] = min(dp[i][k]+dp[k][j]+w(i,k,j) for k in i+1..j-1)
